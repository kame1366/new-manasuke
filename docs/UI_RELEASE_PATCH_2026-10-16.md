# Manasuke 招待制公開向け UI仕上げパッチ（2026-10-16）

ベース: `Manasuke_invite_release_candidate_2026-10-15.zip`

## 変更点
- 学習対象の通常一覧をコンパクトにし、有効な学習対象だけを表示。
- Goalの通常一覧をコンパクトにし、有効なGoalだけを表示。
- アーカイブ済みStudyTargetを通常の編集候補から除外。復元UIは維持。
- 目標の重要度を `高・中・低`、学習単位を `問題・単語・ページ` 等の日本語で表示。
- 日付のみのGoal期限を、ユーザーが選択した日付（例: `10/25まで`）で表示。
- 計画を7日間すべての日付で表示（予定なしの日も分かる）。
- 日付に曜日、日別の予定件数・合計分数を追加（キャンセル済みの分数は合計から除く）。
- 計画カードから通常の「自動生成」を省略。ユーザーの編集・追加・キャンセルは表示。
- 予定は目安で、休憩・調整できることを明記。

## 適用手順
1. Streamlitを停止する。
2. Gitで現状をコミットするか、プロジェクトフォルダをバックアップする。
3. **現在のローカル版がベースZIPから変更されていないか確認する。**
4. 変更がない場合のみ、パッチZIPの `pages/01_learning_settings.py`、`pages/02_plan.py`、`ui/formatters.py` を同じ相対位置にコピーする。
5. `tests/test_release_ui_formatters.py` を追加する。
6. `python -m pytest -q tests/test_release_ui_formatters.py tests/test_release_plan_ui.py` を実行する。
7. `streamlit run app.py` で起動し、以下の画面を目視確認する。

**注意:** このZIPは2026-10-15版の公開候補コードを元に作成しています。その後ローカル側でページを編集していた場合、単純なファイル上書きは避け、差分を統合してください。
